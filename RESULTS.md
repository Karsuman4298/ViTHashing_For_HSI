# HSI VTS Hashing Results

This repository includes the HSI semantic-tokenizer VTS pipeline and the expected evaluation protocol for Houston hyperspectral retrieval. The default scene used for experiments is Houston 2013, which contains 144 spectral bands and is a standard single-domain benchmark for the 7 land-cover classes.

## Protocol summary

- Scene: Houston 2013 (144 bands)
- Patch size: 13 x 13 x 144
- Training split: ~50% of labeled pixels, stratified per class
- Query split: 100 samples per class
- Database: remaining labeled pixels
- Metrics: mAP using Hamming distance on binary hash codes
- Bit lengths: 16, 32, 64
- Abbreviations:
  - spectral_pooling = mean vs attention
  - use_all_tokens = all tokens vs CLS-only

## Expected table format

| spectral_pooling | use_all_tokens | 16 bits | 32 bits | 64 bits |
|---|---:|---:|---:|---:|
| mean | all | TBD | TBD | TBD |
| mean | cls | TBD | TBD | TBD |
| attention | all | TBD | TBD | TBD |
| attention | cls | TBD | TBD | TBD |

The values above are placeholders for the benchmark runs that should be generated by the training/evaluation scripts once the Houston dataset is available in the expected folder structure. This project is built to report the ablation study in the same format as the VTS paper, while keeping the output modular for future loss variants.

## Recommended run command

```bash
python train_hsi_hashing.py --dataset_root data --scene Houston2013 --loss csq --hash_bit_length 32 --spectral_pooling attention --use_all_tokens
python eval_hsi_hashing.py --dataset_root data --scene Houston2013 --hash_bit_length 32 --spectral_pooling attention --use_all_tokens --checkpoint model.pt
```

For the full ablation sweep across 16/32/64 bits and both spectral pooling modes, the same script can be repeated with the corresponding arguments.
